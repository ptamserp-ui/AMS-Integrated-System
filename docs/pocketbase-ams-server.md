# Catatan PocketBase historis

PocketBase bukan driver aktif pada Linux staging yang terakhir diverifikasi dan tidak perlu dipasang untuk deployment Firebase. Catatan dan konfigurasi lama disimpan di [arsip PocketBase](../archive/pocketbase-legacy/README.md); jangan menggunakannya sebagai prosedur deployment atau backup saat ini.

Untuk runtime dan penyimpanan aktual lihat [README](../README.md), [panduan Linux](./panduan-deploy-vps.md) dan [evaluasi staging](./evaluasi-staging.md). PostgreSQL shadow juga belum terhubung ke runtime.
